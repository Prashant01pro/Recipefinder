# Recipe Finder (React + Vite)

Welcome to **Recipe Finder** — a fast and modern web app built with **React** and **Vite** that helps you discover new recipes in seconds.  
Just type an ingredient or a dish name, and the app will fetch real recipes with images, ingredients, and instructions. Simple, clean, and fun to use.

🔗 **Live Demo:** [Recipe Finder on GitHub Pages](https://prashant01pro.github.io/Recipefinder/)

##  What This App Does

-  Search recipes by ingredient or name  
-  See full recipe details — ingredients, steps, and category  
-  Browse mouth-watering images of dishes  
-  Built with **React + Vite**, so it’s lightning fast  
-  Fully responsive and works great on mobile devices  
-  Hot Module Replacement (HMR) for instant updates while developing  

Whether you’re a home cook, a foodie, or just hungry for ideas — this app has you covered.

## Tech Stack

This project is built using a minimal but powerful setup:

| Technology | Role |
|-------------|------|
| **React** | Frontend UI and component logic |
| **Vite** | Development server and bundler |
| **JavaScript (ES6)** | Core app logic and API integration |
| **CSS3** | Styling and layout |
| **Recipe API** | Provides real-time recipe data (like [TheMealDB](https://www.themealdb.com/)) |
